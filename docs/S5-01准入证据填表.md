## 0. 填写规则

1. 每域只登记四字段：**批准主体** · **适用版本/范围** · **批准时间** · **证据位置**（内部审批单号、合同编号、网盘标签等）。
2. **禁止**写入：合同全文、学生/监护人个人信息、密码、Cookie、密钥、可直接登录的测试凭据。
3. 填完后把索引贴回聊天或更新开发计划 S5-01 表「状态」列；由开发会话核对后才可能解除阻塞。
4. 六域未齐备前，**不得**启动技术架构第 18.5 节实施顺序 (b) 及之后步骤。

## 1. 本地已确认执行政策（只读摘要，≠ 真实准入）

以下取舍已在阶段五**本地隔离**范围确认并验收，仅约束合成账号/原创材料演练：

| 项 | 本地已确认内容 | 明确不覆盖 |
| --- | --- | --- |
| 材料与账号 | 仅原创教材/题目与合成账号 | 真实学生、第三方教材 |
| 隐私申请 | 全局本人申请 → 受控 CLI 批准执行；无公开管理员删除 HTTP | 生产运维身份与双人审批制度 |
| 部分删除 | 有保全证据时必须标明部分删除，不假称完全匿名 | 法定留存矩阵与例外审批 |
| 维护窗口 | 停写维护；本地建议上限 DB 256MiB / 文件 1GiB / snapshot 45s；超限失败 | 生产 RPO/RTO、不停机备份 |
| 恢复 | 默认全身份锁定；独立最新删除/撤销账本必需；缺账本不解封；只恢复到新空隔离库/文件根 | 跨故障域生产恢复指标 |
| 扫描 | 真实 ClamAV clean 路径已验；两项 EICAR 感染用例按修订 11 暂缓 | 生产扫描库新鲜度与感染准入 |
| 部署 | 本机回环/隔离演练；第 18.5 节仅设计方向确认 | TLS/生产认证、真实试点发布 |

证据入口：开发计划修订 19/20/25；技术架构第 18.4.1、18.5 节。
