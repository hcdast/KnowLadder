# 知阶 KnowLadder UI / UX 设计方案

> 状态：设计已确认并用于 `prototype/` Vue 交互原型；本文件保留设计规范，不是高保真图稿。实际验证范围见交互原型方案第 12 节。
> 关联文档：[项目方案](项目方案.md) · [技术架构方案](技术架构方案.md) · [交互原型方案](交互原型方案.md) · [文档导航](README.md)
> 范围：初中数学、学生 Web 与最小内容管理 Web。14个页面已实现，路由以交互原型方案为准；真实后端不在本轮范围。
> 本文所有章节、题干、分数、时间、次数、进度与场景内容均为**示例数据**；尺寸、色值、断点与无障碍阈值为**候选设计规范**，不是实测结论。

## 1. 背景、现状与问题

产品规划规定学习闭环和品牌，技术架构采用NestJS与MongoDB。`prototype/`已实现14页内存演示；独立 `server/`与`web/`已实现真实账号认证、强制改密和组织权限，并已按授权完成阶段二内容工作台、学生阅读与私有附件的本地实施及必要验证，最终 WSL2 全套72项通过，真实浏览器证据及Windows历史限制见技术架构第18.1.1节。练测、学情仍属后续阶段，不能把演示交互当作真实学习后端，也不能把本地验证等同于生产批准或全部视觉/跨平台验收。

当前缺口是可执行的任务路径与恢复规则，而不是更多指标：学生需要知道下一步做什么；阅读进度不能当掌握度；练习解析不能泄露到考试；「已输入、已保存、已交卷、已评分、已发布、报告已更新」不能混为成功；内容编辑与审核发布不能成为一个无说明的按钮。

### 1.1 目标与非目标

- **目标**：给出页面结构、主动作和退出回路；建立最小 token/组件规范；为正常、空、加载、错误、不可逆状态定义操作；支撑后续原型演示完整闭环及关键异常。
- **非目标**：真实登录、后端接口与数据库实现、真实评分、文件服务、正式 Logo 资产、教师/家长业务端、小程序、复杂批注、知识图谱编辑器、真实智能诊断或已经验证的无障碍合规。
- 原型题型限定单选、多选、数值填空；练习首期采用提交后看解析，不要求逐题评分。未来如开放提示/提前解析，必须记录曝光并影响独立证据口径。

## 2. 角色、任务与信息架构

| 角色 | 核心任务 | 边界 |
| --- | --- | --- |
| 学生 | 阅读、练习、参加测验、理解结果、回到教材 | 仅本人空间；未发布考试信息不能通过成长/错题旁路泄露 |
| 内容编辑 | 教材章节与题目草稿、预览、送审、按意见修改 | 不审核自己提交版本；已发布版本不可原地改写 |
| 内容审核者 | 查看版本与依据、退回、审核发布 | 不在审核页静默改题；关键操作指向明确版本并留痕 |

管理职责不意味着可随意查看学生数据。原型入口是**场景选择，不是真实登录**；持续显示「交互演示 · 示例数据」，编辑/审核切换只是场景模拟，不是权限安全证明。

### 2.1 导航与路径

- 学生一级导航固定为 **首页 / 课本 / 练测 / 成长 / 错题**。
- 首页 S01；课本 S02 → S03；练测共享入口区切换自主练习 S04 与测验说明 S06；成长 S09；错题 S10。
- 练习：S04 → S05 → S08 → S03 / S04 / S09。
- 测验：S06 → S07 → S08 → S09。S07 使用专注布局，不显示可误触的普通一级导航。
- 管理独立：A01 内容工作台 / A02 教材章节 / A03 题目编辑 / A04 审核发布，不混入学生导航。
- 场景选择与异常演示控件属于原型工具，不新增业务页面 ID。

从错题/推荐进入章节或练习时保留来源，展示「返回错题」「返回推荐」；无来源时返回所属栏目。返回保留筛选、章节定位与合理滚动位置，不能只依赖浏览器回退。

## 3. 视觉方向与最小设计系统

### 3.1 方向：清晰的学习工作台

浅色阅读底、深色正文、蓝色定位、克制分隔线。首页突出一个继续任务；阅读页突出内容；管理页突出列表、表单、版本。避免满屏指标卡、卡片套卡片、装饰性渐变、玻璃效果和排行榜焦虑。只有需比较的内容才并排，不给每个信息块加容器。

品牌使用文字「知阶 KnowLadder」，**不新增 Logo 资产**。项目方案 A/B/C 概念保留，但正式素材未交付前不把占位图称为 Logo。「每一步，都算数」只作首页辅助语，不遮盖任务。

### 3.2 色彩 tokens（候选）

| Token | 值 | 使用规范 |
| --- | --- | --- |
| `color.brand` | `#1E6FFF` | 保留品牌蓝：标识、当前导航标记、局部图形；不默认承载小号浅色文字 |
| `color.growth` | `#2ECC8F` | 保留辅助绿：完成标记；不默认白字 |
| `color.emphasis` | `#FF8A3D` | 保留强调橙：适量提醒；不默认白字 |
| `color.canvas` | `#F5F7FA` | 保留页面背景色 |
| `color.surface` | `#FCFDFE` | 阅读与表单背景 |
| `color.text` | `#172A3A` | 正文，绿/橙色块上文字的候选色 |
| `color.text-muted` | `#46566B` | 时间、版本与辅助说明，不以透明度替代文字色 |
| `color.action` | `#174EA6` | 品牌蓝的深色交互派生色：主按钮和正文链接 |
| `color.action-hover` | `#123E85` | 主按钮 hover/active |
| `color.on-action` | `#F5F7FA` | 深蓝按钮文字 |
| `color.border` | `#CBD4DF` | 非关键分隔线，不独立承担控件识别 |
| `color.control-border` | `#63758A` | 输入框及必要控件轮廓 |
| `color.focus` | `#174EA6` | 浅色隔离带外的焦点环 |
| `color.success-text` / `color.success-bg` | `#145C43` / `#E8F7EF` | 成功文字/背景 |
| `color.warning-text` / `color.warning-bg` | `#75400E` / `#FFF1E5` | 警告文字/背景 |
| `color.error-text` / `color.error-bg` | `#9F2435` / `#FCEEF0` | 错误文字/背景 |

**已计算7组静态主题色对，完整状态组合仍待验证，不宣称整站通过。** 后续须覆盖 hover、focus、选中、透明度叠加、图标与控件边界。验收目标为 WCAG 2.2 AA：普通文字至少 4.5:1，大文字至少 3:1，必要图形/控件边界至少 3:1。若不满足，调整语义派生 token，不擅改品牌本色。绿橙优先用深色字或上述浅底/深字状态组合，并附「已完成」「待确认」等文字，不只依靠红绿区别状态。

### 3.3 字体、空间与动效

| 类别 | 候选规范 |
| --- | --- |
| 字体 | 中文品牌/重点标题用思源黑体 Bold，正文用常规字重；授权未确认前用系统中文字体回退。英文品牌优先 Montserrat，缺失时回退，不新增远程字体依赖 |
| 字号 | `caption/small/body/reading/h3/h2/h1 = 12/14/16/18/20/24/32px`，实现换算 rem；关键状态不使用 caption |
| 行高 | 正文 1.6、阅读 1.8、标题 1.3；独立公式不挤压正文 |
| 间距 | `space.1…8 = 4/8/12/16/24/32/48/64px`；同组紧、跨组疏 |
| 圆角 | `radius.control=8px`、`radius.panel=12px`；仅必要容器使用 |
| 阴影 | 普通内容无阴影；`shadow.overlay=0 8px 24px rgba(23,42,58,0.12)` 仅用于浮层 |
| 布局 | `layout.max=1200px`、`layout.reading=720px`、`layout.aside=240px` |
| 控件/焦点 | `control.min-height=44px`；`focus.width=2px`、`focus.offset=2px`，深底需浅色隔离带 |
| 动效 | `motion.fast=120ms`、`normal=200ms`，`ease-out`；尊重 reduced motion，不用弹跳/循环脉冲 |

### 3.4 组件契约

| 组件 | 行为与状态 |
| --- | --- |
| `StudentShell` / `AdminShell` | 统一导航、主标题、跳至正文、示例标记；考试专注变体 |
| `Button` / `TextLink` | 每操作区一个主按钮，其他描边/文字；loading 防重复；禁用原因可见，不仅 tooltip |
| `Field` / `Select` / `RadioGroup` | 可见 label、必填说明、关联错误；保留原生键盘行为；多选为 checkbox，数值填空不擅自替学生改答案 |
| `StatusNotice` / `SaveStatus` | 常驻展示断网/冲突/提交未知；不依赖短暂 toast；原型保存状态加「模拟」标识 |
| `QuestionView` / `AnswerControl` | 题干/公式/作答分层；明确模式，考试不加载解析；已答不等于答对 |
| `QuestionNavigator` | 当前/未答/已答/待看均有可读名称，非仅颜色 |
| `EvidenceRow` / `RecommendationItem` | 记录、解释、行动分区；缺证据不画零百分比 |
| `ContentTable` / `VersionBadge` | 可见状态、版本、更新时间；移动端保持字段标签 |
| `ConfirmDialog` | 仅用于终结提交、丢弃未保存修改、发布；安全动作初始焦点，Esc 关闭并还焦点 |
| `LoadingBlock` / `EmptyState` | 保留布局、不填假数字；空态有原因与下一步；错误支持局部重试 |

## 4. 逐页交互规格

所有页面继承第 3 节组件和第 6 节异常契约。加载占位不可误点；错误保留合法输入；没有可用数据不伪造进度。

### S01 学生首页

- **布局**：品牌与导航、辅助口号、一个继续学习任务；可参加测验用列表；下方最近记录及一条解释清楚的建议，不排指标墙。
- **主动作**：「继续阅读」到 S03；进行中会话优先「继续练习/测验」到 S05/S07，显示模式与保存状态。
- **退出回路**：导航通往 S02/S04/S09/S10；完成后由 S03/S08 回首页。
- **关键状态**：首次使用主动作「选择教材」；局部失败不阻塞导航；旧报告显示时间与未覆盖最新作答；待发布测验只显示状态。

### S02 教材目录

- **布局**：教材版本选择、授权说明、章节树/列表；显示阅读位置，不写已掌握。
- **主动作**：选章进入 S03；换教材版本显式改变范围，不偷偷沿用旧版知识点。
- **退出回路**：回 S01；S03 返回保留章节展开和位置。
- **关键状态**：无教材提示暂无可用教材并可返回；无匹配可清空筛选；授权过期停止预览；失败可重试，不用未授权文件兜底。

### S03 章节阅读

- **布局**：教材/章节面包屑；左目录、中间正文与例题、右知识点与练习入口；正文宽度受控，小屏目录可展开。
- **主动作**：「练习本节」到 S04，带教材版本与知识点；章末「下一节」。
- **退出回路**：回 S02；由错题/推荐进入时提供来源返回并恢复定位。阅读位置不作为掌握证明。
- **关键状态**：正文加载、公式/图片局部失败、章节下线、关联习题空分别提示；局部失败不挡已读正文；无练习仍可回目录；复杂批注不放伪可用按钮。

### S04 练习设置

- **布局**：练测入口区、范围摘要、知识点、基础/提升/挑战和题型；说明提交后查看解析，重练区分已见题。
- **主动作**：「开始练习」成功创建后到 S05；处理中防重复创建。
- **退出回路**：回来源章节或练测入口；存在进行中练习时先提供「继续已有练习」，新建明确为另一组记录。
- **关键状态**：范围缺失定位字段；无题提示调整范围，不扩大学段补数；失败保留设置；创建结果未知先恢复同次创建。

### S05 练习作答

- **布局**：「练习」标签、题号、保存状态、题干答案、答题导航；底部上一题/下一题/结束并提交。首期不显示提前解析和逐题判分。
- **主动作**：「下一题」；最后「结束并提交」在 S05 本页打开未答检查与确认面板；确认受理并取得 submission_id 后才进入 S08。单选、多选、数值填空使用相应原生控件。
- **退出回路**：「保存并离开」回 S04，仅确认后称已保存；失败时可留页重试或明确接受未保存风险。提交后解析可回 S03。
- **关键状态**：未答可继续，导航标未答；断网/冲突保留输入；终结后只读，重练新会话。未来提示/答案曝光须持续标记并按规则降权或排除独立证据。

### S06 测验说明

- **布局**：练测入口与可参加测验列表；选中后显示范围、题型、时长、开放/关闭时间与时区、次数、成绩发布政策、断网/截止规则。
- **主动作**：「开始测验」确认规则，创建成功到 S07。截止取时长结束与关闭时间较早者；不足完整时长需在开始前说明。
- **退出回路**：回练测列表/S01；已有会话「继续测验」，已有提交到 S08；恢复不重置计时。
- **关键状态**：未开放给开放时间；次数耗尽/关闭禁用并解释；资格变化按服务器拒绝处理，不由前端放行。

### S07 测验作答

- **布局**：专注顶栏：测验名、剩余时间、保存状态；题干答案、题号导航；底部「检查并交卷」。无提示、解析或正确性。
- **主动作**：作答并保存；在 S07 本页打开交卷检查面板，可关闭并定位具体未答题；受理且取得 submission_id 后进入 S08。
- **退出回路**：「暂时离开」说明计时不暂停及未保存风险，回 S06 可继续同一有效会话；不依赖浏览器必弹离开确认。
- **关键状态**：离线可保留本页输入但不称已保存；多端冲突暂停写；本地到零锁编辑并查服务器；切屏不自动判作弊；已受理后只读。

### S08 提交与结果

- **布局**：仅在取得已受理的 submission_id 后呈现「受理信息 → 批改/发布状态 → 结果」，发布后才显示成绩、逐题回顾及下一步。提交前检查及受理未知留在 S05/S07 本页面板，不要求尚不存在的提交 ID。
- **主动作**：待处理态「刷新状态」；已发布态「回到教材/针对练习/查看学情」。
- **退出回路**：回 S01/练测并能回访；重练显式新建，不改原成绩。提交前取消检查返回题目由 S05/S07 处理。
- **关键状态**：未知不判成功或失败；`202` 只代表持久化受理；待复核不编分数；延后发布无分数/解析；截止只用此前保存答案；评分失败不要求重交；结果发布但报告滞后时分开显示。

### S09 学情推荐

- **布局**：周期/教材范围、生成时间与覆盖提醒、知识点证据表；推荐按依据/建议/行动组织，默认不用雷达。
- **主动作**：缺证据「先做诊断练习」到 S04；有证据「回顾章节」到 S03 或「针对练习」到 S04；带入范围。
- **退出回路**：回 S01；来自 S08 可回结果；允许跳过建议并自主选教材。
- **关键状态**：无证据「待诊断」而非零；旧数据标时间；无候选解释原因并给授权章节；过期/失效推荐重新获取；未发布考试不得进入依据明细泄露结果。

### S10 错题

- **布局**：知识点/来源/时间筛选；题目摘要、模式、有效评分时间；展开本人作答、已公开解析与章节。
- **主动作**：「同类练习」到 S04，「回到教材」到 S03；原题重练标已见题。
- **退出回路**：回 S01；阅读/练习返回恢复筛选和位置。
- **关键状态**：空态「当前没有可回顾错题，可继续章节学习」，不宣称全掌握；未发布考试不入列表；失效题不偷换旧版本；重批变化注明更新；不提供无持久化契约的删除伪功能。

### A01 内容工作台

- **布局**：独立导航、当前示例职责/范围、草稿/待审/退回列表，显示版本、作者、更新时间；无学生成绩看板。
- **主动作**：编辑者到 A02/A03 继续编辑，审核者到 A04 查看待审。
- **退出回路**：回原型场景选择；管理切换不得静默丢未保存内容。
- **关键状态**：无待办说明范围；失败重试；无权限不暴露其他组织；角色切换醒目标模拟。

### A02 教材章节

- **布局**：教材版本、章节层级、标题/知识点/正文预览、授权来源与期限、引用状态。
- **主动作**：「编辑草稿/提交审核」；已发布只允许「创建新版本」；题目入口 A03、审核入口 A04。
- **退出回路**：回 A01 保留筛选；未保存离开提示；发布预览只读。
- **关键状态**：授权缺失阻断送审并定位；资源隔离/不可用标状态；无章节引导草稿。素材状态只模拟，不伪装真实上传/扫描/文件服务。

### A03 题目编辑

- **布局**：身份、版本、状态；题型/题干/选项/答案/解析/知识点/难度依据/来源表单；旁边学生预览，底部保存/送审。
- **主动作**：「保存草稿」与「提交审核」分开；预览只显示学生可见题面，不混入受保护答案。
- **退出回路**：回 A01/A02 来源；未保存可留页或明确放弃；退回意见随草稿保留。
- **关键状态**：缺项有汇总与字段定位；公式失败保留原输入；冲突比较本地/最新版本，暂停覆盖；审核中/发布版只读；无确定规则的题型不宣称可自动评分。

### A04 审核发布

- **布局**：待审列表按教材版本/题目版本区分，显示版本详情、版权依据、修改差异、提交人、意见和记录；教材详情显示完整章节结构和资源引用，题目详情显示题干/答案/解析。
- **主动作**：「退回修改」必填原因；「审核通过并发布」明确确认目标版本；作者不能自审，不能通过切换按钮文案绕过职责。
- **退出回路**：回 A01；退回后编辑经 A02/A03 修改再送审；发布后只读，改动开新版本。
- **关键状态**：对象更新后禁用旧预览发布，要求重看；共用校验包含授权有效、资源 ready、作者非审核者；教材校验章节结构和知识关联，题目额外校验答案及评分规则，不能用答案必填阻断教材发布。发布结果未知先查状态；旧会话保持冻结内容。

## 6. 状态、异常与恢复契约

### 6.1 练习与考试硬隔离

| 维度 | 练习 S05 | 测验 S07 |
| --- | --- | --- |
| 来源 | 授权已发布题目 | 冻结试卷版本，服务端校验次数/开放区间 |
| 提示/答案 | 首期提交后解析；未来提前查看必须记录曝光 | 考试中不展示、不返回、不预加载，不能只 CSS 隐藏 |
| 时间 | 按规则，可无截止 | `deadline_at` 为准，离开不暂停 |
| 终结 | 原记录只读，可新建重练 | 受理/截止后只读，前端不能重置次数 |
| 结果 | 评分完成且允许公开后展示 | 同时满足发布政策和复核条件 |
| 学情 | 独立作答与已见题重练分清 | 未发布信息不能经报告/推荐/错题泄露 |

共享组件不等于共享答案数据；未来安全边界是服务端 DTO 与授权。原型浏览器代码可检查，其中示例答案不构成保密考试。

### 6.2 自动保存与冲突

1. 改答先标「未保存」，同会话保存串行处理；合并尚未发出的同题修改，不让自动保存与交卷竞争。
2. 只有响应确认对应草稿版本，且此后没有新编辑，才显示「已保存至服务器」。较旧响应不能把新输入误标为已保存。原型文案明确为模拟。
3. 切题可继续但保存失败常驻；交卷先停止新自动保存、等待在途写状态明确，再以最新确认修订和最终答案提交。未列出的答案沿用已保存内容，不静默清空。
4. `409 REVISION_CONFLICT` 后暂停保存，拉取最新状态，并列「本页输入/服务器已保存」和题号。可采用服务器版本；若仍可写，逐题确认保留本页输入再用新修订保存，绝不静默覆盖。已终结/截止则无覆盖动作。
5. **原型仅内存保存，刷新按场景恢复初始状态**；入口和有草稿页面显式提示，重置演示二次确认后统一清空所有更改。模拟已保存不等于跨刷新或跨设备持久化。生产本地草稿方案另行确认隐私/留存，不默认永久存学生答案。

### 6.3 关键异常到动作

| 事件 | 可见状态 | 允许动作与恢复原则 |
| --- | --- | --- |
| 断网/保存超时 | 连接中断，本页修改尚未保存 | 可继续本页输入，提醒刷新/离开风险；恢复先查会话/修订，不能按离线时间补交逾期答案 |
| `429` | 保存暂受限制，尚未确认 | 按 `Retry-After` 有界重试；持续失败提供手动重试 |
| `503` | 暂无法确认保存/提交结果 | 不声称受理成功；查询或按原请求契约重试 |
| 双击交卷 | 正在提交，答案锁定 | 同次终结同一 `Idempotency-Key`，不生成重复成绩 |
| 提交结果未知 | 正在确认是否已受理，请勿重复交卷 | 在 S05/S07 本页查询，取得 submission_id 后才进入 S08；原 key/原正文恢复；不能仅凭一次 in_progress 就换 key，须确认旧请求未提交且不会迟到生效才能恢复编辑/新请求 |
| 幂等正文冲突 | 本次请求状态需要恢复 | 停止变更正文重试，查原会话/提交；提供安全 `request_id`，不让刷新掩盖错误 |
| 本地计时到零 | 时间可能已结束，正在确认 | 锁定编辑并查询；服务器确认仍有效才校准恢复，不按本地时间宣告提交成功 |
| 服务端截止 | 已截止，正在确认最终提交 | 不接收新答案；只用截止前保存答案；worker 尚未终结时继续待确认，不宣称丢失或补交 |
| `202` | 提交已受理，正在批改 | 可安全离开并回访，原会话只读；不等于成绩已生成 |
| `needs_review` | 作答已保留，等待复核 | 查状态/回首页，不造最终分数、不要求重做 |
| 延后发布 | 已受理，成绩待发布 | 有 `release_at` 才显示时间/时区；到时间但复核未完仍等待，不自动揭示 |
| 评分失败 | 结果暂未生成，正在处理 | 状态查询和问题编号，不要求重交，不显示默认零分 |
| 学情落后 | 学情更新中，当前报告生成于… | 结果与报告分开；旧报告标未覆盖新记录，不造新推荐 |
| `401` | 生产需重新认证；原型仅状态演示 | 考试计时不停，认证后恢复原会话；场景切换不是认证 |
| `403`/敏感`404`/内容失效 | 内容暂不可用 | 清除受保护展示，给安全返回；不暴露他人存在性；换题显式新会话，不偷换历史题 |
| `422` | 字段错误与汇总 | 聚焦错误摘要，通过摘要链接定位字段；保留合法输入，不原文回显敏感服务器信息 |

状态查询采用有界退避，离开页面停止无用查询，超窗口给手动刷新，不无限后台轮询。技术文档尚未穷尽恢复查询与管理端点，正式接入前补齐 OpenAPI；本文不私自新增 URL。

### 6.4 学情与推荐解释

依次呈现：**记录**（范围、周期、独立证据数、最近时间）→ **解释**（规则与限制、已看答案记录的处理）→ **建议**（为何推荐、适用范围、可跳过）→ **时效**（生成时间及是否包含最新评分）。不向学生倾倒内部水位编码，但用 `status/generated_at/source_watermark` 判断状态。

示例：「等式变形：当前独立作答证据不足，暂不判断掌握情况。建议先做本节诊断练习。」无证据不用零值；无候选给原因和已授权章节；不承诺提分、不把阅读时长当努力或能力；考试未发布时不在解释中暗示新薄弱点。

### 7.2 键盘与辅助技术

- 使用真实 `header/nav/main/aside`、有序标题、跳至正文；换页焦点到主标题，返回列表恢复合理位置。
- Tab 顺序与阅读一致；单选方向键、checkbox 空格、按钮 Enter/Space；不覆盖输入法/浏览器快捷键。
- 题号可读名称含第几题及已答/未答/当前/待看，不靠色块。
- 保存状态非打断播报，截止/提交错误在状态变化时播报；倒计时不逐秒进入 live region。
- 弹窗有名称、焦点约束、安全关闭和焦点归还；展开控件有 `aria-expanded`，隐藏内容不可被 Tab 进入。
- 字段错误关联输入；链接有下划线或等效非颜色标记；图标按钮有可访问名称；控件焦点始终可见。
- 公式优先 MathML 或经验证的可访问渲染；图形有语义说明，不把整题做成无替代文本图片，也不在替代文本泄露答案。
- 延时便利依赖考试政策和服务端授权，前端不得私自延长截止。

本轮已执行键盘、响应式几何和7组主题色对检查，具体证据见交互原型方案第12节；屏幕阅读器、真实设备、完整视觉状态与整站合规尚未验证，**不能标注整站无障碍认证通过**。
