## 运行真实账号与内容系统

使用Node.js 24 LTS，安装 `server/` 与 `web/` 依赖，准备真实MongoDB副本集及 `server/.env`（从 `.env.example`复制并生成自己的密钥），先执行 `npm --prefix server run migrate -- --inspect` 只读预检，再在获准数据库执行迁移并启动API与Web。默认API为3000、真实Web为5174，与5173演示原型分离。账号发放与认证备份见第19节；扫描worker、清理、usage、受控能力及私有目录要求见第18.1.1节。`auth-backup` 不覆盖内容与文件。

**无内置测试账号或默认密码。** 账号由受审计CLI创建，首次登录必须改密；真实Web已接通教材/题目编辑审核、学生阅读和私有附件、练习/考试/结果及最小考试管理，以及独立学生“学情、错题与推荐”入口和阅读进度。评分需运行独立`assessment:worker`，学习投影需`learning:worker`，均不能由文件扫描worker代替。感染验收暂缓不改变运行要求；不回退演示数据、不提供模拟学情。上传必须配置真实ClamAV及安全私有目录；本地`SCAN_DATABASE_MAX_AGE_HOURS=168`仅为隔离验收值，不是生产政策。POSIX路径安全及负例的Ubuntu22.04 WSL2实测为历史记录。

阶段四`learning:once`单轮执行，`learning:reconcile`默认只读、修复需显式actor/reason审计。当前API须先停旧写进程，经只读inspect和授权迁移到**v7**后启动，不混跑不理解学习账本或阶段五删除屏障的旧写入进程；仅限已确认的本地隔离范围，生产迁移与部署另行审批。Web学情/报告/错题/推荐与阅读恢复已完成本地功能验收；首次证据不足不显示假零分，管理冲突能力隐藏学习入口，管理预览不登记阅读。阅读409须明确选择服务器或本页进度，未知响应仅原事件重试；未确认位置不保存到浏览器，刷新可能丢失。`reading:cleanup`默认只读，`--apply`仅允许本地`kl_test_`隔离库；运行边界见第18.3.1节二十一/二十二。容量实验需显式`TEST_LEARNING_CAPACITY=true`，修订13结果为历史证据。

## 运行交互原型

在仓库根目录运行 `npm --prefix prototype ci`，再运行 `npm --prefix prototype run dev`，打开 `http://127.0.0.1:5173/`。

入口提供首次学习、继续学习、内容编辑和内容审核；顶部“演示控制”支持异常状态、身份切换与重置。数据仅存内存，刷新会重置；不提供真实登录、文件上传或生产评分。构建、预览命令及验证限制见[交互原型方案第12节](交互原型方案.md#12-运行方法与本次验证记录)。

## 评审入口

1. 确认首期学段、学科、教材版本及内容授权来源。
2. 确认首期用户端、学习闭环和后续全学段扩展顺序。
3. 在 NestJS + MongoDB 已确定的基础上，确认事务副本集部署、文件存储方式、图数据库引入条件、团队资源与预算。
4. 确认未成年人保护、监护关系、学校数据边界及数据保留要求。
5. 确认掌握度与推荐的解释口径、验证方法和上线门槛。
6. 阶段一至五的约定本地范围已完成并分别留有验证记录；真实第三方材料版权、未成年人隐私、生产扫描政策、受控操作人和试点范围仍须有权主体确认。全业务备份恢复已在隔离环境演练，不等于生产RPO/RTO或上线批准；commit/push亦未获授权。
